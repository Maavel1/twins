# Twins React

React/Vite версия лендинга Twins. Проект уже разбит на компоненты, данные вынесены отдельно, карта встроена через бесплатный iframe-виджет Яндекс Карт.

## Запуск

```bash
npm install
npm run dev
```

Локальный адрес по умолчанию: `http://127.0.0.1:5173`.

## Сборка

```bash
npm run build
npm run preview
```

## Структура

- `src/App.jsx` - сборка страницы и состояние модальных окон.
- `src/components/` - блоки интерфейса: шапка, hero, карта, мастера, тарифы, footer.
- `src/data/siteData.js` - навигация, категории, карточки мастеров, тарифные преимущества и ссылки карты.
- `src/index.css` - Tailwind, базовые стили и анимации.

## Что уже готово

- Реальная карта на главном экране.
- Адаптивный мобильный экран с картой и нижней панелью мастеров.
- Базовые модальные окна для входа, регистрации, PRO и записи.
- SEO meta-теги, favicon, `.env.example`.
